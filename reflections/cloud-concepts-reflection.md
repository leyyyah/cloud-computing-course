# Cloud Computing Concepts Reflection

Cloud computing plays an important role in my daily life because I use different cloud-based applications for communication, entertainment, and online transactions. 
Three cloud services that I regularly use are Facebook Messenger, Netflix, and GCash. These applications make my daily activities more convenient because I can access them anytime and anywhere through the internet.

Facebook Messenger is classified as **Software as a Service (SaaS)** because it provides messaging and communication services without requiring users to install or manage servers.
It uses the **Public Cloud** deployment model since it is available to millions of users worldwide through Meta's cloud infrastructure.

Netflix is also an example of **Software as a Service (SaaS)** because it allows users to stream movies and TV shows online without managing the underlying system. 
It is classified under the **Public Cloud** deployment model because its streaming services are available to subscribers over the internet using cloud-based servers.

GCash is another **Software as a Service (SaaS)** application because it provides digital payment and financial services through a mobile application. 
It also uses the **Public Cloud** deployment model since users can securely access their accounts and perform transactions through cloud-based services managed by GCash.

Git and GitHub are important tools for cloud computing projects because they provide version control, allowing developers to keep track of every change made to files and source code. If an error occurs, previous versions can easily be restored. GitHub also helps teams collaborate by allowing multiple developers to work on the same project, review changes, and merge updates without overwriting each other's work. 
Using GitHub makes cloud projects more organized, improves teamwork, and reduces the risk of mistakes when managing cloud resources.
